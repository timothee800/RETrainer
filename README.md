The trainer (.exe file) was generated through Cheat Engine, with a .CT file as the source. To generate it open the .CT file on CE and save it as a Cheat Engine Trainer Standalone (*.EXE).

The .CT file contains all the code: Cheat Engine assembler scripts and the trainer's lua code. The file is viewable through notepad or other text editor apps.

I want to note here that CE version 7.6 was used to generate the trainer instead of the latest 7.7. This could slightly change the final .EXE.

The trainer's lua code (final part of the .CT file) and the assembler scripts that inject to the targeted game process (.asm file) are also available separately. The .asm file can be copy pasted into CE to create the script entries and includes all the assembly code, among other details. Both of these files are included in the main .CT file.


It is important to state here that the whole trainer is structured around CE, there isn't a source code beyond the aforementioned.
